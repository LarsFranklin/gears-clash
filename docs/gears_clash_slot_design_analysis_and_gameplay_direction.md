# Gears Clash — Slot Design Analyse & Gameplay Direction

## Ziel dieses Dokuments

Dieses Dokument sammelt die wichtigsten Erkenntnisse aus modernen High-Volatility 5x5 Slots (insbesondere aus analysierten Referenz-Screenshots) und definiert die Gameplay-Richtung für **Gears Clash**.

WICHTIG:
- Keine 1:1 Kopie existierender Spiele.
- Keine geschützten Assets, Namen oder Themes übernehmen.
- Fokus auf Gameplay-Gefühl, Spannung, Flow und moderne Slot-Präsentation.

---

# 1. Core Direction

## Gears Clash soll sein:

- Moderner 5x5 High-Volatility Slot
- Industrial / Gear / Machine Theme
- Multipliers als Herzstück des Spiels
- Wenige, aber starke Features
- Sehr visuelles, explosives Gameplay
- Framework-agnostisch & modular aufgebaut
- Wiederverwendbar / lizenzierbar

# 4. Gameplay-Philosophie

## Das Spiel lebt NICHT von normalen Symbolen.

Das Spiel lebt von:

- Reel Multipliers
- VS / Gear Clash Mechanics
- Sticky Wilds
- Bonus Features
- Escalation
- Multiplikator-Kombinationen

Normale Symbole dienen primär:

- RTP-Verteilung
- Grundaktivität

- Kleine Basis-Gewinne

# 5. Feature-Persönlichkeiten

## gears_clash

### Gefühl

```txt
Explosiv
Chaotisch
High Action
```

### Fokus

- Viele VS-Symbole
- Mehrere Reel-Multipliers
- Große Gewinnspitzen
- Volatile Freispiele

### Mechanik

- Zwei Gear-Multipliers treten gegeneinander an
- Gewinner-Multiplikator übernimmt die komplette Reel
- Reel wird Full-Reel-Wild
- Multipliers addieren sich

Beispiel:

```txt
x2 VS x6
=> x6 gewinnt
=> gesamte Reel wird x6 Wild Reel
```

Wenn mehrere Reel-Multipliers beteiligt sind:

```txt
x6 + x4 = x10
```

NICHT multiplikativ.

---

## heist_run

### Gefühl

```txt
Kontrollierter Aufbau
Sticky Spannung
Langsame Eskalation
```

### Fokus

- Sticky Wilds
- Freispiele
- Immer stärker werdendes Grid

### Mechanik

- Sticky Wilds bleiben während Freispiele aktiv
- Wilds können optional Multipliers tragen
- Ziel: möglichst viele Wild-Reels aufbauen

---

## deadlock_mode

### Gefühl

```txt
Tension
Survival
Collection
Overdrive Explosion
```

### Struktur

## Phase 1 — Collection

- Leeres Grid
- 3 Lives
- Sammeln von:
  - Wilds
  - Multipliers
  - Special Gears

WICHTIG:

Gesammelte Symbole bleiben NICHT sichtbar auf dem Grid.
Sie werden in einen:

```txt
Overdrive Storage
```

übertragen.

### Regeln

- Wenn mindestens ein Symbol landet:
  - Lives reset auf 3

- Wenn kein Symbol landet:
  - Lives -1

- 0 Lives:
  - Overdrive Phase startet

---

## Phase 2 — Overdrive

- Gesammelte Symbole werden auf dem Grid verteilt
- Finaler Reveal Spin
- Alle gesammelten Multipliers aktiv
- Maximale Eskalation

# 9. Wichtige Erkenntnisse aus den Referenz-Screenshots

## 9.1 Große Symbole

Die Symbole sind:

- groß
- dominant
- leicht lesbar
- nicht zu detailliert

### Wichtig für Gears Clash

Nicht:

```txt
kleine mobile icons
```

Sondern:

```txt
große massive mechanische symbole
```

---

## 9.2 Sehr enge Reel-Struktur

Die Reels haben:

- kleine Gaps
- hohe Dichte
- wenig Leerraum

Dadurch:

- wirkt alles aktiver
- mehr Spannung
- mehr Action pro Spin

---

## 9.3 UI ist extrem minimalistisch

Der Fokus liegt fast komplett auf:

- Grid
- Reels
- Spin Button

Nicht auf Menüs.

---

## 9.4 Der Spin Button ist dominant

Der Spin-Button ist:

- groß
- zentral
- die wichtigste Aktion

Für Gears Clash:

- großer Metall-Button
- Industrial Glow
- Massive Präsenz

---

## 9.5 Gewinnlinien sind dünn und leuchtend

Keine dicken Cartoon-Linien.

Für Gears Clash:

- Electric Cyan
- Orange Energy
- Tech Glow
- Sparks

---

## 9.6 Freispiele sind das eigentliche Spiel

Das Basegame dient primär als:

```txt
Setup für Eskalation
```

Die Freispiele liefern:

- große Multiplier
- Reel Explosions
- massive Hits

---

## 9.7 Multipliers sind additiv

NICHT:

```txt
x5 * x5
```

SONDERN:

```txt
x5 + x5 = x10
```

Das macht das Spiel:

- kontrollierbarer
- lesbarer
- fairer balancierbar

---

## 9.8 Das Spiel lebt von Almost Hits

Sehr wichtig:

Fast-Bonus-Momente erzeugen Spannung.

Beispiel:

```txt
2 Bonus Symbole landen
Reel 5 stoppt langsam...
fast Bonus...
aber doch nicht
```

Das erzeugt:

- Spannung
- Emotion
- Erwartung

---

## 9.9 Presentation > reine Mathematik

Die wichtigsten Dinge moderner Slots:

- Animation Timing
- Reel Feel
- Sound Timing
- Delays
- Bonus Build-Up
- Screen Shake
- Multiplier Reveal

Nicht nur:

```txt
RTP Mathematik
```

# Kern-Erkenntnisse aus den Referenz-Slots

## 1. Bonusspiele verändern das komplette Spielgefühl

Moderne Freispiele fühlen sich wie ein eigener Spielmodus an:

- eigener Hintergrund
- andere Farben
- eigene HUD-Elemente
- neue Sounds
- neue FX
- eigene Spannungskurve

### Umsetzung für Gears Clash

### gears_clash
Thema:

```txt
FACTORY OVERDRIVE MODE
```

Visuelle Elemente:

- glühende Maschinen
- orange/rote Alarmfarben
- elektrische Entladungen
- Funkenregen
- Rauch und Dampf
- rotierende Zahnräder
- vibrierende Kamera
- blinkende Warnlampen

---

## 2. Eigene Bonus-HUDs

Bonusspiele benötigen eigene HUD-Elemente.

### Geplante HUD-Elemente für Gears Clash

Oben:

```txt
OVERDRIVE MULTIPLIER x14
```

Links:

```txt
ACTIVE GEAR REELS: 3
```

Unten:

```txt
OVERHEAT LEVEL
```

Zusätzliche HUD-Ideen:

- Stability Meter
- Reactor Energy
- Active Wild Reels
- Collected Sparks
- Gear Power
- Machine Integrity

---

## 3. Langsame Eskalation statt sofortiger Explosion

Moderne Slots bauen Spannung langsam auf:

- kleine Treffer
- mehr Wilds
- höhere Multipliers
- volle Reels
- Mega/Epic Wins

### Wichtig für Gears Clash

Das Spiel soll wirken wie:

```txt
Eine Maschine die langsam außer Kontrolle gerät.
```

Das bedeutet:

- mehr FX mit steigender Spannung
- stärkere Sounds
- mehr Screen Shake
- mehr Lichtblitze
- UI beginnt zu glühen
- Umgebung wird instabiler

---

## 4. Full-Reel-Mechaniken erzeugen Gewicht

Große vertikale Features wirken massiv.

### Umsetzung für Gears Clash

### Gear Reactor Reel

Eine komplette Reel kann zu einer:

```txt
x7 OVERDRIVE REEL
```

werden.

Mögliche Visuals:

- gigantisches Zahnrad
- rotierende Energiewelle
- elektrische Leitungen
- überladene Metallplatten
- Plasma-Effekte

---

## 5. Freispiele müssen deutlich stärker wirken

In modernen Slots enthalten Freispiele:

- mehr Wilds
- mehr Multipliers
- weniger tote Spins
- höhere Spannung

### Für Gears Clash

Freispiel-Modi erhöhen:

- Wild-Chance
- Multiplier-Chance
- Overdrive-Chance
- Full-Reel-Chance

---

## 6. Collection-Systeme sind extrem stark

Die Referenzspiele zeigen:

- Wild Counter
- Multiplier Counter
- Sammelmechaniken
- Reset-Systeme

Das erzeugt:

- Progression
- Spannung
- Momentum
- Aufbaugefühl

# DEADLOCK MODE (stark inspiriert von modernen Collection-Boni)

## Phase 1 — Machine Recovery

Der Spieler sammelt:

- Wild Gears
- Energy Charges
- Overdrive Multipliers

System:

```txt
3 Stability Charges
```

Jeder Treffer:

```txt
RESET STABILITY
```

Der Spieler versucht die Maschine stabil zu halten.

---

## Phase 2 — OVERDRIVE RELEASE

Die Maschine bricht vollständig aus.

Effekte:

- alle gesammelten Wilds werden verteilt
- alle Multipliers werden aktiv
- massive Explosionen
- finale Chaosrunde
- maximaler Screen Shake
- rote Alarmlichter

---

# Fazit

Die Referenzspiele zeigen klar:

- Freispiele sind eigene Spielmodi
- Eskalation ist wichtiger als reine Mathematik
- große visuelle Momente erzeugen Spannung
- Progression und Collection-Systeme sind extrem stark
- Full-Reel-Features erzeugen Gewicht
- das Spielgefühl ist wichtiger als reine Auszahlungstabellen

Gears Clash sollte deshalb massiv auf folgende Fantasy setzen:

```txt
Industrial Reactor Chaos
Machine Overload
Mechanical Escalation
Unstable Factory Core
```
