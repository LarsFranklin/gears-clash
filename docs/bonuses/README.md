# Bonus-Dokumentation

Jeder der drei Bonus-Modi von Gears Clash hat eine **eigene Spezifikationsdatei**. Die technische Bonus-ID (API, Schema, Code) ist jeweils in **Snake-Case**; der **Anzeigename** im Spiel kann freundlicher formuliert sein.

**Bonus-übergreifend:** [cross-cutting-bonus-rules.md](cross-cutting-bonus-rules.md) (Scatter-Strip-Isolation, Schnittstelle Gears während anderer Modi).

| Bonus-ID | Dokument | Anzeigename (Ziel) |
|-----------|-----------|---------------------|
| `heist_run` | [heist-run.md](heist-run.md) | **Heist Run** — Scatter „Heist“, FS-Tabelle, Retrigger +4, Sticky-Zell-Wilds |
| `gears_clash` | [gears-clash.md](gears-clash.md) | **Gears Clash** — Freispiel-Bonus + Kampf/Full-Reel |
| `deadlock_mode` | [deadlock-mode.md](deadlock-mode.md) | **Deadlock Mode** — Collection + Overdrive, selten/stark |

Übergeordnete Kurzbeschreibungen aller Modi: [../gears_clash_slot_design_analysis_and_gameplay_direction.md](../gears_clash_slot_design_analysis_and_gameplay_direction.md).
